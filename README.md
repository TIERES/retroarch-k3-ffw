# RetroArch with Kaillera Neplay support
Unofficial version of RetroArch with Kaillera Neplay support, based on the original [RetroArch](https://github.com/libretro/RetroArch) version 1.16.0.3 and Kaillera netplay code by you_are_doomed.

Rewritted and optimized kaillera code, added support Open Kaillera n02 callbacks also for Linux version and other improvments.

Latest Kaillera clients and other stuff can be found here: https://kaillerareborn.github.io
